# Friends of the Irving Museums — website

A single static page, `index.html`, served by GitHub Pages. There is no build step: edit the file, commit, and the site updates in about a minute.

- **Membership checkout links** live in the `CONFIG` block near the bottom of `index.html` (`DEFAULT_CHECKOUT`, `MONTHLY_CHECKOUT` and the per-level `CHECKOUT` map). Point each level at its own payment link so members land on checkout with their level already chosen.
- **Logo:** `assets/fotim-logo.png`.
- **Domain:** friendsoftheirvingmuseums.com is owned by the City of Irving, which points its DNS here.
